# Return Policy — Standard Operating Procedures

## Section 1: Return Eligibility Windows

- **Electronics (phones, laptops, tablets, TVs):** 10-day return window from delivery date.
- **Apparel and footwear:** 30-day return window from delivery date.
- **Home appliances:** 10-day return window from delivery date.
- **Books, consumables, perishables:** Non-returnable under any circumstances.
- **Large appliances (ACs, refrigerators, washing machines):** Installation must be completed within 3 days of delivery. Return window is 30 days post-installation.

## Section 2: Conditions for Return

Items must meet ALL of the following conditions:
1. Item must be unused, unwashed, and in original packaging.
2. All tags, accessories, and manuals must be included.
3. For electronics: Factory seal must be intact OR item must show a documented defect.

## Section 3: Exceptions and Override Authority

### 3.1 Late Return Requests (Past Window)

- Return requests up to **5 days past** the standard window: Tier 1 agents may approve at their discretion. Log reason in audit trail.
- Return requests **6–15 days past** the standard window: Requires **Tier 2 supervisor approval**. Customer must provide reason. Approved cases limited to manufacturing defects or carrier delay evidence.
- Return requests **beyond 15 days past** the standard window: Escalate to **Customer Experience Manager**. Do not commit to approval verbally.

### 3.2 Wrong Item Delivered

- Always approved regardless of return window elapsed.
- Agent must verify: item received (photo + description) ≠ item ordered (catalog comparison).
- Initiate replacement dispatch AND return pickup simultaneously.
- Do not wait for return pickup before dispatching replacement for orders under Rs. 10,000.
- For orders above Rs. 10,000: Replacement dispatched only after return is received at warehouse.

### 3.3 Damaged Item on Arrival

- Always approved regardless of return window elapsed.
- Agent must confirm: customer has photographic evidence or unboxing video.
- If evidence is unavailable: Escalate to fraud check before proceeding. Do not reject outright.
- Offer replacement first; offer refund if replacement SKU is out of stock.

## Section 4: Non-Returnable Scenarios

- Items damaged due to customer misuse (dropped, water damage, unauthorized repair).
- Items sold under "Clearance" or "Non-returnable" tags.
- Digital goods and software licenses once activated.
